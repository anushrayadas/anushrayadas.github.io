Flagship Project

Unified AI Platform

Problem
Getting an answer from company data meant writing SQL, knowing the schema, or waiting on an analyst — even for simple questions.
Input
Natural language questions typed into a chatbot, answered directly against a live, schema-aware database — Pharma based dataset.
Architecture
Intent-routing pipeline: a schema-aware LLM call classifies each query (SQL, dashboard, segmentation, or forecasting) and scopes it to only the relevant tables/columns before anything runs.
Workflows
SQL path generates and executes the query, then converts raw results into a plain-language answer. Dashboard path uses a Planner LLM to output a JSON layout, turned into chart data and an HTML template in parallel, then merged into an interactive dashboard.
Backend & AI
Multi-step LLM orchestration with structured JSON outputs at every decision point, schema-grounded prompting to cut hallucinated tables/columns, and a modular router so segmentation and forecasting plug into the same core.
Results
One chatbot that answers direct questions in plain English and auto-builds full interactive dashboards for exploratory questions — from the same query box.
Business impact
Removes the SQL/BI bottleneck between business users and their own data — turns "ask an analyst" into "ask the platform," without sacrificing accuracy.

AI Product · Backend

Segmentation AI Platform

Problem
Business users needed to run advanced segmentation on their own data without writing code or waiting on a data science team.
Dataset
Any user-uploaded structured dataset (CSV/Excel) — not domain-specific, validated on upload with an automated schema check.
Approach
End-to-end no-code pipeline: AI data-health report → AI feature recommendations → custom feature engineering → AI algorithm recommendation → clustering → auto-labeled profiling (High/Moderate/Low) → AI-generated insights. Migrated from a Streamlit prototype to a production FastAPI backend with a Figma-designed UI.
Algorithms
K-Means, DBSCAN, and Gaussian Mixture Models, auto-ranked by silhouette, Davies–Bouldin, and Calinski–Harabasz scores, with the best fit highlighted for the user.
Backend & data
Built the FastAPI APIs for upload, preprocessing, clustering, and profiling; used PostgreSQL for run/segment storage and Qdrant + RAG to power a natural-language "Ask AI" chatbot over saved segmentation results.
Results
Shipped a working self-serve platform: upload a dataset, get an AI-recommended algorithm and cluster count, interpretable segment profiles, and a chatbot that answers questions like "which segment has the highest spend?" in plain language.
Business impact
Let non-technical users self-serve advanced segmentation, cut manual data-prep effort, and made results interpretable without statistical expertise — accelerating customer/member segmentation workflows.

Case Study

Unified: turning raw HCP data into a segmentation strategy

Pharma commercial teams were engaging HCPs uniformly, with no reliable way to tell a high-value prescriber from a low-engagement one. Unified was built to close that gap — end to end, from raw data to a segmentation and forecasting system the business could act on.

01 · Data Sources

Sourcing and generating the dataset

Researched real-world HCP engagement data structures and generated a representative dataset covering prescribing behavior, specialty, region, and interaction history.

02 · Data Engineering

Cleaning and structuring

Resolved missing values, duplicate records, and inconsistent categorical fields; built SQL pipelines to join and structure the data into an analysis-ready format.

03 · Feature Engineering

Building the feature set

Derived behavioral features — prescribing frequency, engagement recency, channel mix, specialty-adjusted volume — used as inputs to segmentation.

04 · Segmentation Methodology

Clustering into segments

Standardized features and applied K-Means clustering, selecting cluster count via elbow method and silhouette score, then validated with hierarchical clustering.

05 · Evaluation

Evaluation metrics

Assessed cluster quality with silhouette score and within-cluster variance, and validated forecasting outputs with MAPE / RMSE against holdout periods.

06 · AI Analytics Layer

Forecasting and insights

Layered forecasting models on top of segments to project engagement trends per group, and summarized patterns into plain-language insights.

Insights Generated

  • A small share of HCPs drove a disproportionate share of engagement value — a clear "protect and grow" segment.
  • A distinct growth-potential segment showed rising engagement trends worth proactive investment.
  • A low-engagement segment was consuming outreach resources with minimal return.

Recommended Business Actions

  • Prioritize field and digital engagement budget toward the high-value and growth-potential segments.
  • Redesign outreach cadence for the low-engagement segment to reduce wasted effort.
  • Re-run segmentation quarterly to catch HCPs migrating between segments early.
